## What was built

All modules from phase 00 now have real implementations:

### core:model
- `ChatEvent` sealed class with 8 variants: `Delta`, `ToolCallStarted`, `ToolCallProgress`, `ToolCallFinished`, `MessageCompleted`, `Error`, `Unknown` — all carrying `conversationId`
- `ChatMessage`, `ChatState`, `ToolCall` data classes
- `ToolCallStatus` enum: `Started`, `Progress`, `Finished`, `Error`

### core:network
- `OkHttpClientFactory`, `BearerAuthInterceptor`, `BackoffPolicy` (full-jitter), `AppError` sealed class

### core:security
- `KeystoreSecretStore` (AES-GCM via Android Keystore)
- `BearerTokenRepository` (encrypted storage)
- `SecurityModule` (Hilt singleton provider)

### core:database
- Room DB, `ChatMessageDao`, `ChatMessageEntity`

### core:designsystem
- `AssistantTheme` (dynamic color on Android 12+)
- `MessageBubble`, `ToolCallChip` (4 states), `StateComponents`

### backend-client
- `ChatApiClient` — `POST /v1/chat` (SSE stream) + `GET /v1/health`
- `SseFrameCodec` — parses `data: {...}` per `docs/CONTRACT.md`, tolerant (unknown types → `Unknown`, malformed JSON → `Unknown`, never throws)
- `ChatReducer` — pure `(ChatState, ChatEvent) -> ChatState`, handles delta-before-marker synthesis
- `SseFrameCodecTest` — 14 tests covering all event types, edge cases, malformed input
- `ChatReducerTest` — 12 tests covering delta synthesis, message completion, tool calls (parallel + error), conversation_id propagation

### feature:onboarding
- `OnboardingViewModel` — paste token + URL → `GET /v1/health` → store via `BearerTokenRepository`
- `OnboardingScreen` — text fields + loading state + error display

### feature:chat
- `ChatViewModel` — owns `StateFlow<ChatState>`, sends via `ChatApiClient`, collects SSE, reduces via `ChatReducer`
- `ChatScreen` — LazyColumn of messages + streaming content + tool call chips + input bar

### app
- `AppModule` (Hilt) — provides `BearerTokenRepository` singleton
- `AppNavHost` — onboarding → chat navigation

## SSE contract compliance

Implemented exactly per `docs/CONTRACT.md`:
- Request body: `{ "conversation_id": "...", "message": "..." }`
- Event types: `delta` (field: `content`), `tool_call_started` (`id`, `name`, `args_json`), `tool_call_progress` (`id`, `note`), `tool_call_finished` (`id`, `ok`, `summary`), `message_completed` (`message_id`), `error` (`message`, `retryable`)
- `[DONE]` → `MessageCompleted`
- Unknown types → `Unknown` (never throws)
- Delta-before-marker synthesis handled in reducer
